# 知刻 · 邮电抖课 Demo

使用 React 19、Vite、Chart.js 和 Lucide 图标制作的手机端三页短视频学习平台。电脑打开时也使用固定手机视口，手机打开时铺满屏幕。

## 本地运行

```sh
npm install
npm run dev
```

生产构建：`npm run build`，输出目录为 `dist/`。

## 页面与交互

- 首页：参考短视频平台的竖屏讲师授课画面，关注 / 推荐 / 课程标签、播放暂停与进度演示、点赞、收藏、分享、知识点检索。
- 任务：底部弹出三题随堂小测，红色错误与绿色正确反馈、解析、结果、重练。
- 我的：李同学个人中心，Chart.js 周/月学习时长、学习路径、推荐复习、徽章、段位排名。
- 全部视口均使用手机布局与固定底部导航；个人学习中心内部纵向滚动。

演示内容使用本地模拟数据与AI 生成的讲师授课静帧与模拟播放进度，不含外部视频源或后端。收藏与小测完成状态保存到 localStorage；成绩、时长与排名为展示数据。
