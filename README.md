# 知刻 · 邮电抖课 Demo

使用 React 19、Vite、Chart.js 和 Lucide 图标制作的响应式三页学习平台。

## 本地运行

```sh
npm install
npm run dev
```

生产构建：`npm run build`，输出目录为 `dist/`。

## 页面与交互

- 首页：关注 / 推荐 / 课程标签，WiFi 速率提升知识动画、播放暂停与进度、点赞、收藏、分享、知识点检索。
- 任务：三题随堂小测，红色错误与绿色正确反馈、解析、结果、重练。
- 我的：李同学个人中心，Chart.js 周/月学习时长、学习路径、推荐复习、徽章、段位排名。
- 移动端使用固定底部导航；桌面端使用学习工作台布局。

演示内容使用本地模拟数据与无声 CSS 知识动画，不含外部视频源或后端。收藏与小测完成状态保存到 localStorage；成绩、时长与排名为展示数据。
